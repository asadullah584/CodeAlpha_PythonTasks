# Hangman Game - CodeAlpha Internship Task

A simple command-line Hangman game implemented in Python.

## Features
- Random word selection from a predefined word list.
- Input validation to check for single alphabetic characters.
- Tracks guessed and wrong letters to avoid repeated inputs.
- Player gets 6 total incorrect attempts before game over.
